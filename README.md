# ネオンブレイク / Neon Break

A portrait one-thumb boss fight for the mobile browser.

Drag to slide the ship. It sits a short way above your finger and follows it exactly. If a bullet, laser, or missile passes close without touching the hitbox, that graze is a just dodge: a short slow-motion hit, then a burst of triple damage. One bullet does not both graze and hit on the same pass.

The boss hangs at the top of a neon street. Straight shots, a beam that sweeps across the screen, and homing missiles each glow before they fire. Under half health it mixes two of those at once. Five hits end the run. Tap to go again. The result is your time, your grazes, and a rank: S, A, or B. S still requires a clear with no hits.

```bash
npm install
npm test
npm run dev
```
